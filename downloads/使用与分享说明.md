# 拾题 1.0 · 使用与分享说明

## 现在就能分享给安卓同学

把 `shiti-android-v1.0.0.apk` 通过 QQ、网盘或其他支持 APK 文件的方式发给同学。接收方把文件下载到手机，点开并按系统提示安装“拾题”。某些聊天软件不允许直接打开 APK，可先保存到手机的“文件”应用。

安装后也可以在 App 顶部点击“安装与分享”→“分享安卓安装包”，调起手机系统分享面板，选择发送给同学。这个功能只分享应用安装包，不会带上你的错题或学习记录；系统分享流程尚未实机验证。

- 适用 Android 9 及以上；手机的 Android System WebView / Chrome 需保持更新。
- 这是独立安装包，无需应用商店账号、电脑、开发者模式或 root。
- 首次安装时，安卓可能要求允许当前浏览器或文件管理器“安装未知应用”，按系统正常流程完成即可。
- 练习、答案、分步讲解和资料考点索引已包含在安装包里，第一次打开也可离线练习；外部资料链接需要联网。
- 每个人的错题与学习记录只保存在自己的手机中。卸载 App 或清除应用数据会清除这些记录，目前不提供跨设备同步。

安装包已完成 Android 构建、包名/版本/嵌入内容检查和 APK 签名校验。当前环境没有安卓实机或模拟器，因此尚未完成手机实机测试。

## iPhone 与网址分享

iPhone 使用可安装网页应用（PWA）版本。发布后，把 HTTPS 网址发到班级群即可：

1. 用 Safari 打开网址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”，名称保留为“拾题”。

安卓也可以使用同一网址，在 Chrome / Edge 菜单选择“安装应用”或“添加到主屏幕”。微信内的浏览器通常不提供安装入口，可先选择“在浏览器中打开”。

网页内“安装与分享”提供安装步骤；在真实 HTTPS 站点会显示当前站点的二维码、复制链接与系统分享按钮。本地地址、安卓内置页面和离线文件不会生成无效分享链接。

首次联网打开网页并完成离线缓存后，网页版本可断网继续练习。更新时会提示安装新版本，不会主动清空错题记录。

## 将网页发布成真实网址

`shiti-pwa-v1.0.0.zip` 是完整的静态网站发布包，解压后根目录应直接看到 `index.html`、`sw.js`、`manifest.webmanifest`、`icons` 和 `assets`。

### 方法一：上传到静态网站托管

可使用支持 HTTPS 的静态网站托管。比如 Netlify 的手动发布入口 `https://app.netlify.com/drop`：登录后上传解压出的文件夹，成功后使用托管平台实际给出的 HTTPS 网址。不要把聊天中的工作区文件路径或容器地址当作分享网址。

目前尚未在任何公网托管平台发布此版本；托管平台的注册、可用地区和套餐以其实际页面为准。

### 方法二：使用现有 GitHub 仓库

项目已准备 `.github/workflows/pages.yml`：

1. 把完整项目代码保存到自己的 GitHub 仓库中。
2. 仓库 Settings → Pages → Source 选择 GitHub Actions。
3. Actions → “Publish Shiti mobile web app” → Run workflow。
4. 部署成功后，使用 Pages 页面实际显示的网址进行手机验证，再分享给同学。

这是手动触发的部署流程，不会仅因收到分享包自动公开上传的原始试卷。

本次云环境的 GitHub API 请求被网络代理拒绝，尚未启用或执行远程 Pages 发布。已在云环境配置草稿补充 `api.github.com` 和该仓库 Pages 域名要求；保存配置不等于网站已上线。

## 当前内容范围

支持数学、英语各 4 个考点、3 档难度、原创同类题、分步讲解与错题复习。18 份上传 Word 已整理部分文字/扫描索引与 10 个代表性短摘录，保留来源状态。两份大 PDF 尚未读取，指定教材全文与 B 站讲解内容也尚未完整接入。

题目由本地规则构造，并非大模型任意出题，不把原创题标为历年真题。发布包不包含完整上传原卷、听力音频、签名私钥或任何账号凭据。
